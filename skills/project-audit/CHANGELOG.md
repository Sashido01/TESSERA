## 0.0.5 — План повторных проверок DELTA

Детерминированный delta_plan.py проверяет явно переданные DAG и распространяет инвалидацию. При изменении глобального контекста или графа требует полного повторного обследования. Не переносит PASS и не удостоверяет входы. 14/14 изолированных Linux-тестов; полный CI, тег и фактическая активация обязательны. Сверены исторические результаты CI и выпуска 0.0.4.

## 0.0.4 — Реестр доказательств

Добавлен Evidence Core — локальная проверка явно переданного JSON-реестра доказательств. Строго валидирует поля, ссылки, области, снимок и отпечатки; сохраняет противоречивые PASS/FAIL и отмечает STALE, UNBOUND и INDIRECT. Не читает проект, не исполняет проверки и не удостоверяет факты. Windows 11 / Python 3.14.3: 15/15 тестов. Полный CI каталога и отдельный тег навыка требуют завершения приёмки.

## 0.0.3 — Локальное наблюдение состояния Git

Git Inspector: HEAD (включая unborn/detached), счётчики статуса, refs и remote, повторные наблюдения, явный STALE. Локальные Linux тесты 13/13; без вывода имён файлов и адресов remote; не атомарный снимок и не проверка содержимого. Обновлены инструкции, документация и структурная регрессия. Windows и полная приёмка открыты.

Исправлен ложный DEVICE_BOUNDARY на Windows (#80), усилена регрессия отсутствия чтения содержимого (#77); 21/21 Linux-тестов Inventory Engine, модель Windows RED→GREEN. Реальные Windows CI и scanner verdict ещё не подтверждены.

- Git Inspector: явный allowlist окружения дочернего Git вместо передачи всех переменных (HIGH E2); абсолютный git.exe/git. Граница аудита гипотетического примера усилена после реальной приёмки Codex. Повторные scanner и агентная приёмка обязательны.

- Тестовые загрузчики inventory и Git Inspector используют обычный импорт с ограниченным путём и явной проверкой происхождения модуля; удалено исполнение через importlib loader, добавлены проверки импорта. Сканирование и повторные тесты обязательны.

## 0.0.2 — Ограниченная инвентаризация метаданных

Опциональный локальный инструмент, относительные пути, счётчики, маркеры, лимиты, видимые исключения, SHA-256 метаданных (не содержимого), запрет известных перенаправлений и перехода на другое устройство. 17 локальных тестов Linux; Windows, полный CI и независимый выпуск не подтверждены. Уровень II PARTIAL.

Подготовлен отдельный локальный план тестов; preflight зависит от PR #70 и требует CI.

## 0.0.1 — Кандидат уровня I

Двуязычная инструкция, 30 направлений, FAST/FULL/DEEP, доказательства, охват, отчёт, 20 поведенческих сценариев, пять уровней развития. DELTA и инструментальное ядро запланированы. Реальные агентные испытания и самостоятельная публикация не выполнены.
