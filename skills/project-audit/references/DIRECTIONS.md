## Профили (комбинируются)
Desktop — запуск, DPI, состояния, установщик. Web — API, браузер, доступность. Mobile — разрешения, устройства, жизненный цикл. CLI — аргументы, коды выхода, ошибки. Библиотека — API, совместимость, пакет. AI/ML — данные, модель, inference, метрики, лицензия. AI-agent/Agent Skills — инструкции, активация, полномочия, действия, evals. БД — миграции, транзакции, восстановление. Сеть — протоколы, тайм-ауты, отказ соединения. DevOps — конфигурации, CI, инфраструктура. Embedded/IoT — аппаратура и измерения; без устройства не заявляй runtime PASS. Исследования — гипотезы, источники, методология, воспроизводимость. Документация — полнота, противоречия, актуальность. Непрограммные проекты — адаптируй направления, не навязывай Git и сборку.

Используй сначала штатные проверенные инструменты проекта. Дополнительные анализаторы опциональны.
