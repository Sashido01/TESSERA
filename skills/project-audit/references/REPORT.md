# Шаблон отчёта

[**Русский — оригинал**](REPORT.md) | [English — перевод](REPORT.en.md)

## R1. Контекст
Цель, источник, снимок, профиль, режим, полномочия, ограничения, исходное и итоговое состояние.

## R2. Охват
Для каждого направления: применимость (причина), обследованная область, статус проверки (проверено/частично/не проверено/неприменимо), доказательства, остаток. Полностью проверенные направления / применимые направления; частичные отдельно. При неизвестном знаменателе не рассчитывай процент. Охват не равен готовности.

## R3. Матрица требований
ID, источник, критерий, реализация, тест, доказательство, статус, уверенность, остаток. Файл теста не является результатом запуска. Компонент без связи с целью требует исследования, а не автоматически считается дефектом.

## R4. Находки
ID, приоритет (P0 критический/блокирующий, P1 существенный, P2 улучшение), область, наблюдение, доказательство, последствие, уверенность, контрпроверка, рекомендация, критерий исправления. Отделяй гипотезы и опровергнутые находки.

## R5. Проверки и риски
Команды, реальные результаты, пропуски, среда и снимок; исторические отчёты отдельно. Укажи риски, блокеры, непроверенные области и действия владельца.

## R6. План
Задача, приоритет, зависимости, критерий приёмки, необходимый доступ, независимая работа. Не выдумывай функции. Аудит не означает выполненное исправление. Выдели блокирующие критерии выпуска отдельно.

При разрешении сохранить отдельные отчёты используй Markdown и JSON/JSONL. Автогенерация и строгая схема ещё не реализованы.
