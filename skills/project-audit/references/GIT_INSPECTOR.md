# Git Inspector — кандидат уровня II

[**Русский — оригинал**](GIT_INSPECTOR.md) | [English — перевод](GIT_INSPECTOR.en.md)

`python scripts/git_inspector.py --root <project-root>` получает HEAD (включая unborn/detached), счётчики изменённых, конфликтных и неотслеживаемых путей, локальных веток, аннотированных и прочих тегов, число remote. GitHub и сеть не требуются. Имена путей, веток и адреса remote не выводятся. Две последовательные сверки status/refs/remote names обнаруживают часть изменений: OBSERVED — одинаковые наблюдения, STALE — различие (код 1); ошибка Git/входа — код 2. SHA-256 status и refs — отпечатки наблюдаемых данных, а не содержимого или атомарного снимка. Счётчик аннотированных тегов не доказывает корректность релизов.

Использовать только доверенный стабильный checkout, установленный Git и разрешённую команду. Git status может читать содержимое и выполнять локально настроенные фильтры; инструмент не песочница. Унаследованные GIT_* переменные исключены, optional locks, fsmonitor и глобальная/системная конфигурация отключены, lazy fetch запрещён в поддерживающем Git. Не запускает сетевые команды. Не учитывает рабочие деревья submodules, игнорируемые файлы, содержимое, remote refs и подмены, исчезнувшие между наблюдениями. 15 секунд на команду, 4 MiB после захвата, не жёсткая граница памяти или потомков. Не использовать как доказательство безопасности или чистоты всего проекта. Локальные Linux тесты 13/13; Windows и CI NOT_VERIFIED.
