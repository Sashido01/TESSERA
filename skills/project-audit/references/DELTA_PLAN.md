# DELTA — план повторных проверок (кандидат)

[**Русский — оригинал**](DELTA_PLAN.md) | [English — перевод](DELTA_PLAN.en.md)

Команда `python scripts/delta_plan.py --manifest <manifest.json>` сравнивает только два явно предоставленных графа, не читает проект, не исполняет проверки, не обращается к Git или сети. Структура v1: `{schema_version: 1, previous: snapshot, current: snapshot}`; snapshot = `{scope, context_sha256, coverage_declared_complete, nodes}`; nodes — массив `{id, fingerprint, depends_on}`. Scope/id — неприватные метки; отпечатки — 64 строчных hex или null. depends_on — ID прямых зависимостей. Контекстный отпечаток должен включать версии анализаторов, политику, среду, конфигурацию и другие глобальные входы. Неполноту отмечать false, неизвестные отпечатки — null. Не выдавать метаданные или SHA коммита за хеш содержимого.

Алгоритм проверяет DAG, отклоняет дубликаты и неизвестные ссылки. Изменение scope, контекста, состава узлов, рёбер или заявленная неполнота требуют FULL_RECHECK для всех текущих узлов; удалённые узлы перечисляются отдельно. Иначе изменённые/неизвестные отпечатки инвалидируют узел и все транзитивно зависимые узлы. Обход O(V+E), сортировка результата O(V log V). PLAN_ONLY, даже если список пуст, не удостоверяет полноту/отпечатки/свежесть. Evidence reuse NOT_AUTHORIZED, audit_status NOT_VERIFIED. Удалённый узел не считается устранённой находкой. Нельзя переносить PASS автоматически; фактические результаты и доказательства проверять отдельно по [Evidence Core](EVIDENCE_CORE.md).

До 2 MiB JSON, 2000 узлов и 20000 рёбер на граф, дубликаты ключей отклоняются. 0 — валидный план, 2 — ошибка входа. Состояние между сессиями, построение графа, подтверждение полноты, content hashing, TTL, проверка происхождения и интеграция с evidence остаются открытыми. Ограничения не sandbox. 14/14 изолированных тестов Linux Python 3.13.5; полная CI/Windows/реальный агент не проверены для кандидата.
