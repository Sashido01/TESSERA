# Протокол доказательств

[**Русский — оригинал**](EVIDENCE.md) | [English — перевод](EVIDENCE.en.md)

## Источники
Различай наблюдение исходника, результат фактически выполненной проверки, внешний отчёт/результат владельца и вывод аудитора. Для каждого доказательства записывай ID, источник, координаты, исследованный снимок, время, область, ограничения. Для исполнения дополнительно — проверенная команда, версия инструмента, окружение, код выхода, результат и отпечаток доступного вывода. Не сохраняй секреты и частные данные.

## Уверенность и статус
Уверенность: CONFIRMED — непосредственно подтверждено; SUPPORTED — есть косвенные свидетельства; HYPOTHESIS — требуется проверка; REFUTED — опровергнуто; NOT_VERIFIED — недостаточно доказательств.
Статус реализации: COMPLETE, PARTIAL, NOT_IMPLEMENTED, NOT_STARTED, BLOCKED, NOT_VERIFIED, NOT_APPLICABLE. COMPLETE только при доказанных критериях приёмки. Отсутствие найденной реализации не доказывает её отсутствие при неполном поиске.

## Актуальность
Привязывай доказательства к SHA и рабочему состоянию, если доступно; иначе явно указывай ограничение. Учитывай локальные изменения, конфигурацию, зависимости, набор тестов и среду. Исторический CI другого SHA не подтверждает новый снимок. Если источник изменился, пометь STALE и повтори применимую проверку либо оставь NOT_VERIFIED.

## Противоречия
Сравни документацию, настройки по умолчанию, реализацию, тесты и реальный результат. При расхождении сохрани обе стороны. Для существенной находки найди контрпример или альтернативное объяснение; если невозможно, обозначь ограничение. Ни успешная сборка, ни тег, ни прохождение статического сканера сами по себе не подтверждают работу продукта.
