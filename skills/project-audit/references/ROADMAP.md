# Развитие Project Audit

[**Русский — оригинал**](ROADMAP.md) | [English — перевод](ROADMAP.en.md)

| Уровень | Содержание | Статус кандидата |
|---|---|---|
| I | Инструкция, направления, доказательства, отчёт, сценарии | PARTIAL: исходники; реальный агент не проверен |
| II | Детерминированная инвентаризация, Git, реестр доказательств | PARTIAL: Inventory и Git Inspector приняты в каталог; Evidence Core интегрируется в 0.0.4 |
| III | Подключаемые анализаторы, графы, прослеживаемость | NOT_STARTED |
| IV | Состояние между сессиями, DELTA, актуальность | NOT_STARTED |
| V | Независимая проверка, семантические индексы, формальные методы | NOT_STARTED |

Следующая приёмка: эталонный валидатор Agent Skills, статические проверки TESSERA, установка и реальная активация в Codex и DeepSeek Harness, E01–E20 со сравнением. Нет обязательных платных API. Семь логических графов (структура, семантика, зависимости, требования, проверки, история, доказательства) — план, не реализованное ядро. Самостоятельный выпуск требует обязательных проверок и точного аннотированного тега.

Git Inspector принят в TESSERA v0.0.76 / Project Audit 0.0.3; нативная полная Windows suite принята в PR #74. Evidence Core добавлен в кандидата Project Audit 0.0.4: явная схема, точные scope и привязка к объявленному снимку, сохранение противоречивых PASS/FAIL. 15/15 тестов прошли на Windows 11 / Python 3.14.3. Полный CI кандидата, независимый тег навыка и применение реальным агентом ещё не подтверждены.
