Следующая приёмка: эталонный валидатор Agent Skills, статические проверки TESSERA, установка и реальная активация в Codex и DeepSeek Harness, E01–E20 со сравнением. Нет обязательных платных API. Самостоятельный выпуск требует обязательных проверок и точного аннотированного тега.

Git Inspector — следующий кандидат уровня II, 13/13 локальных тестов Linux; повторно проверены и перенесены четыре точных Git blob. Два наблюдения не равны атомарному снимку или хешу содержимого. Release Core v0.0.70 подтверждён, Inventory Engine PR #71 принят; main CI и тег v0.0.71 ещё требуют подтверждения. Следующий отдельный компонент — Evidence Core: строгие связи наблюдения, SHA/отпечатка и области доказательства, явные UNKNOWN/STALE, без утверждения полной целостности. Полный CI и реальный Windows открыты.
