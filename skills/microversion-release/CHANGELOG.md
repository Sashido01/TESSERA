# История Microversion Release

[**Русский — оригинал**](CHANGELOG.md) | [English — перевод](CHANGELOG.en.md)

## 0.0.6 — Обязательная новая запись истории

- Completion Gate требует единственный исходный heading и единственную впервые добавленную запись следующей версии с сохранением предыдущей. Заранее объявленная версия, дубли и исчезновение предыдущего заголовка BLOCKED. Четыре новых Git regression methods.
- Минимальное окружение двух диагностических CLI fixtures, только явно необходимые системные ключи и synthetic overrides. Отдельная регрессия. Production-политика и разрешения не меняются. CI и фактическая клиентская приёмка требуются.

## 0.0.5 — Точная цель и защита тестовых фикстур

- Guarded Run требует --expected-version и отклоняет ошибочную цель до тестов; проверены сценарии точного релиза, отсутствующего тега, неверной/старой цели в новых тестах, CI требуется.
- Старые mutating Git fixtures отклоняют наследуемые Git_* до записи; новые изолированные fixtures передают только явный allowlist системного контекста. Production Git context остаётся fail-closed.

## 0.0.4 — Контроль завершения и обязательная приёмка

- Базовый completion_gate.py: проверка точной линейной истории от baseline, VERSION/CHANGELOG, тегов релиза и флагов индекса. Stop adapter с однократным продолжением. Ничего не коммитит и не тегирует.
- guarded_run.py: независимый owner-controlled процесс с PLAN_ONLY по умолчанию, запуском согласованного агента/тестов после --execute, отказом no-op и проверкой неизменности проверенного SHA/тегов. 26/26 тестов Linux на временных Git fixtures и реальных child process; полный CI и реальные клиенты NOT_VERIFIED для кандидата.

## 0.0.3 — Диагностика наследуемого контекста Git

- Команда context сообщает только известные имена блокирующих переменных, не выполняет Git и не меняет окружение. Осиротевшие индексированные Git config overrides отклоняются. Три новых тестовых метода навыка; фактическая клиентская интеграция #81 остаётся открытой. CI и независимый тег обязательны.

## 0.0.2 — Совместимость установщика с Windows

- Безопасный вывод в legacy-кодировку консоли; тесты сравнивают канонические пути, включая короткие имена Windows. Защита перенаправлений и запрет перезаписи сохранены. Нативный повторный CI обязателен.

## 0.0.1 — Начало независимого учёта

- Зафиксирована исходная версия существующего навыка; предыдущая история сохранена в CHANGELOG каталога. Исполняемое поведение не меняется. Независимый релиз требует собственного проверенного аннотированного тега; активация в реальных клиентах не подтверждена.
