# Microversion Release

[**Русский — оригинал**](README.md) | [English — перевод](README.en.md)

Переносимый Agent Skill для микроверсий, проверки релизов и человекочитаемой русскоязычной истории Git. Это первый навык библиотеки [TESSERA](../../README.md).

## Правила

- Начало нового проекта: `0.0.0`.
- Каждое самостоятельное проверенное изменение: PATCH+1.
- `.99` — плановый релизный рубеж, а не верхняя граница рабочих коммитов.
- Если работа завершена и проверки успешны: `0.0.99 → 0.1.0`, `0.1.99 → 0.2.0`, `0.99.99 → 1.0.0`.
- Если работа не завершилась к `.99`: `0.0.99 → 0.0.100 → 0.0.101 → …`. После первого фактически завершившего задачу проверенного трёхзначного PATCH — следующий релиз `.0`.
- Нельзя создавать фиктивные коммиты или выпускать непроверенные релизы.
- Коммиты, аннотированные теги, CHANGELOG и описания релизов — на ясном русском языке.

## Установка

1. Скопируйте **весь каталог** `microversion-release`, включая `SKILL.md`, `references/` и `scripts/`.
2. Для DeepSeek Harness используйте подтверждённый активный `<DSH_HOME>/skills/microversion-release/` или проектный `<project>/.dsh/skills/microversion-release/`. Не угадывайте значение DSH_HOME.
3. Проверьте обнаружение навыка в конкретном профиле. Ручной вызов `/microversion-release` может быть доступен только при подключённом загрузчике Agent Skills.
4. Для Codex и других агентов проверьте их актуальный каталог навыков отдельно; команда установки и автоматическая активация здесь не проверены.
5. Если нужен обязательный контроль каждого коммита, добавьте правила в проектный AGENTS.md или отдельную событийную интеграцию. Один SKILL.md такой гарантии не даёт.

## Проверка

Из каталога навыка:

```bash
python scripts/next_version.py 0.0.99 --mode work
python scripts/next_version.py 0.0.100 --mode release
python -m unittest discover -s tests -v
```

Ожидаемые результаты расчёта: `0.0.100` и `0.1.0`. Калькулятор читает аргументы и **не изменяет Git или файлы**; он не проверяет готовность задачи.

## Старые проекты

Если проект уже имеет теги и другую политику версий, не переписывайте его историю. Включайте новую схему только для следующих изменений и после проверки существующей конфигурации.

## Ограничения

Здесь есть инструкции и калькулятор номеров, но **нет** установленного plugin hook, полноценной системы транзакций Git или автоматической сборки. Работу в реальном Harness ещё нужно проверить на целевой версии среды.

## Язык инструкций

Основная точка входа для агента — [SKILL.md](SKILL.md) на русском языке. Полный [английский перевод](references/SKILL.en.md) предоставлен для чтения; агентные загрузчики должны использовать исходный файл.
