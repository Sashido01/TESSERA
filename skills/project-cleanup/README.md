# Project Cleanup

[**Русский — оригинал**](README.md) | [English — перевод](README.en.md)

Версия 0.0.2 — кандидат PC02; 0.0.1 принят по независимому тегу. Отдельный навык для локальной и GitHub-гигиены, управления размером и предотвращения роста. Установка всей папки; см. [SKILL.md](SKILL.md). Не требует платных API или внешних пакетов.

```bash
python -B scripts/inventory.py --root <project-root>
python -B scripts/inventory.py --root <project-root> --details
```

Первый режим выдаёт только агрегаты; второй добавляет приватные относительные пути крупнейших наблюдаемых REVIEW-файлов (не публиковать). Ничего не удаляет. См. [инвентаризацию](references/INVENTORY.md), [Git/GitHub](references/GIT_STORAGE.md), [дорожную карту](references/ROADMAP.md). PC01: native CI Linux 21 PASS, Windows 20 PASS + FIFO SKIP (v0.0.90). PC02: native CI и агентная приёмка NOT_VERIFIED.

Приватные детали также показывают до 20 крупнейших групп каталогов первого уровня (null — файлы в корне). Агрегация хранит до 8192 групп; private_top_level_complete=false обозначает пропуск групп, не изменение общих метрик. Группа не является разрешённой целью удаления.

Изолированное Linux-доказательство: 18/18 тестов PASS; Git blobs исходника и тестов совпали точно. Синтетическая fixture: 10000 файлов × 128 байт = 1280000 логических байт, три обхода 104/114/103 мс, медиана 104 мс. Не benchmark Windows или реального проекта; native CI и клиентские проверки открыты.

Усиление границ: известные каталоги учётных данных не перечисляются; их объём неизвестен, исключения отражает sensitive_dirs. Явный корень в таком каталоге или Git metadata, домашний профиль и его предки отклоняются. Если профиль не определён — BLOCKED, не изменять окружение хоста. Защитные признаки расширены именами и основами имён учётных данных, ключей и токенов. Регрессии контролируют отсутствие открытия содержимого; это не песочница и не исчерпывающий детектор чувствительных имён.
