# История изменений Project Cleanup

[**Русский — оригинал**](CHANGELOG.md) | [English — перевод](CHANGELOG.en.md)

## 0.0.3 — Устойчивое наблюдение корневого Git marker

- Main 0.0.94 Windows CI 46042052275, job 140651970098: test_git_marker_changed_during_plan FAIL (48 других executions, 2 FIFO SKIP); прежний тест предполагал немедленное изменение метаданных каталога при создании дочернего файла. Заменён реальной подменой каталога с сохранением старого объекта и отдельной инъекцией изменения метаданных. Добавлены отказы при исчезновении marker, неизвестном inode корня/marker и hardlinked .git file. Runtime повторно проверяет ordinary_root и marker identity; не читает содержимое .git, не удостоверяет состояние Git, не разрешает удаление. Требуется новый native CI.

## 0.0.2 — Git-aware план очистки

- Опциональная сверка двух наборов Git-снимков и метаданных, защита HEAD/index/untracked, явные scope, ограничение ресурсов, приватные детали по запросу. Не удаляет и не вызывает Git. 28/28 Linux PASS, включая staged deletion и sparse-index на реальном Git fixture. Native CI и клиентская приёмка открыты.
- PC01 0.0.1 подтверждён независимым аннотированным тегом; Linux 21 PASS, Windows 20 PASS + FIFO SKIP в v0.0.90.

## 0.0.1 — Безопасная инвентаризация и процесс очистки

- Начальный независимый навык, metadata-only inventory, ограничения обхода, классификация REVIEW, агрегаты и локальные детали.
- Правила проверки и очистки локальных файлов, Git, GitHub, профилактика роста и измеримая приёмка. Удаление не автоматизировано; CI и клиентские испытания обязательны.

Изолированное Linux-доказательство: 18/18 тестов PASS; Git blobs исходника и тестов совпали точно. Синтетическая fixture: 10000 файлов × 128 байт = 1280000 логических байт, три обхода 104/114/103 мс, медиана 104 мс. Не benchmark Windows или реального проекта; native CI и клиентские проверки открыты.

- Доработка до merge: исключение каталогов учётных данных, отказ для профиля/его предков, дополнительные защищённые имена и три регрессии, включая отсутствие открытия содержимого. Прежние 18 тестов относятся к предыдущему исходнику; требуется новый CI. Без подавления сканера.
