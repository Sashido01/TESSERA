# Git and GitHub: separate storage domains

[Русский — оригинал](GIT_STORAGE.md) | **English — translation**

Only use a trusted selected Git context. If unsafe, do not strip variables to proceed; report BLOCKED. Begin with `git status --porcelain=v2`, `git worktree list --porcelain`, `git count-objects -vH`, `git ls-files -z`; ignored/untracked via separate `git ls-files --others --ignored --exclude-standard -z` and `git ls-files --others --exclude-standard -z`. Working tree, index, shared object database, refs and remote are separate metrics; do not sum them as physical usage. Keep raw paths private.

For history, optional official [git-sizer](https://github.com/github/git-sizer) (verify version and provenance before installation): reachable large blobs, tree depth, objects, refs. [git count-objects](https://git-scm.com/docs/git-count-objects) reports local loose/pack counters, not server size. [git clean](https://git-scm.com/docs/git-clean) has preview, but ignored does not mean safe; avoid bulk destructive clean. [git maintenance](https://git-scm.com/docs/git-maintenance) and [git gc](https://git-scm.com/docs/git-gc) may affect shared objects, reflog and worktrees; no automatic execution. No aggressive prune, GC or history rewrite for savings. A new deletion commit does not erase historical blobs.

GitHub: separately inventory repository metadata size (approximation), current tracked blobs, Actions artifacts (size/expiry/purpose/release and evidence links), Actions caches (key/branch/access/size), Releases assets, LFS and Packages where applicable and authorized. Missing permission is not zero. Paginate for complete coverage. Artifact totals are not Git size. [Artifact deletion](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/remove-workflow-artifacts) is irreversible; verify preservation of evidence, attestations, release files and reproducibility first. Historical failed runs are not automatically waste. Caches speed CI; compare download/rebuild cost. Agree retention and limits per project/account, see [storage settings](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/enabling-features-for-your-repository/managing-github-actions-settings-for-a-repository), [dependency caching](https://docs.github.com/en/actions/reference/workflows-and-actions/dependency-caching). Exact-ID deletion only with authority and a fresh check. Never publish private paths, tokens or raw reports.

Prevent growth: keep reproducible data out of Git, use narrow ignore rules and dedicated storage for builds/caches, inspect change sizes; do not add automatic limits that break necessary files or release evidence. Local operation remains valid without GitHub.
