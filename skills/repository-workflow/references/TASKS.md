# Задачи и зависимости

[**Русский — оригинал**](TASKS.md) | [English — перевод](TASKS.en.md)

Используй один актуальный источник задач: существующую дорожную карту, локальный реестр или GitHub Issues с зависимостями. Не создавай обязательный дубликат Issues в локальной БД. Снимок для помощника формируется из этого источника; он не изменяет исходный реестр.

Статусы: BACKLOG, READY, IN_PROGRESS, WAIT_DEPENDENCY, WAIT_CI, CI_FAILED, READY_TO_INTEGRATE, WAIT_RELEASE, WAIT_OWNER, BLOCKED, COMPLETE. COMPLETE требует реальные доказательства и выполненные зависимости. Запиши цель, критерии приёмки, время последнего наблюдения, ветку/PR/run и блокер в основном реестре. Старые результаты не переносятся на изменившийся SHA.

## Опциональный локальный планировщик

```bash
python scripts/plan_tasks.py --tasks <task-snapshot.json>
```

Формат снимка:

```json
{"streams":["core","skill-a"],"tasks":[{"id":"T01","stream":"core","priority":"P0","status":"WAIT_CI","depends_on":[],"write_scope":["core"],"resources":[],"read_only":false,"evidence":[]},{"id":"S01","stream":"skill-a","priority":"P1","status":"READY","depends_on":[],"write_scope":["skills/skill-a"],"resources":[],"read_only":false,"evidence":[]}]}
```

Проверяет уникальные ID, неизвестные/циклические зависимости, COMPLETE без ссылки на доказательство, пересечение объявленных областей и ресурсов (включая вложенные пути, без учёта регистра). Выбирает максимум одну доступную задачу каждого потока в указанном порядке, при одинаковом приоритете сначала CI_FAILED. WAIT_CI и другие удерживающие состояния не препятствуют независимой работе. Путь `.` резервирует всю область записи. Пустая область допускается только для явно read_only. При NO_READY_WORK сверяй блокеры и выбирай только обоснованное исследование.

Ограничение: помощник не проверяет истинность ссылок, состояние GitHub, скрытые зависимости, реальную идентичность файлов/симлинки и не резервирует ресурсы атомарно. Это только рекомендация по предоставленному снимку. Перед действием повторно проверь актуальность и согласуй владение задачей.

### Уточнение переносимости 0.0.2

Области нормализуются casefold + NFC; эквивалентные Unicode-пути конфликтуют консервативно. Зарезервированные имена устройств Windows (включая имена с расширениями) и суррогаты отвергаются. CLI отклоняет повторяющиеся ключи JSON. Проверка DAG обходит каждый узел и ребро один раз (O(V+E), без учёта иных стадий планирования); 1000 задач в цепочке проверены. Это не сравнение файловой идентичности: 8.3 aliases, hardlinks, junctions, симлинки и внешние процессы требуют отдельной сверки. Read-only не резервирует запись: согласуй стабильность источника отдельно. 17/17 тестов Linux, нативный Windows и реальное исполнение агентами не проверены.
