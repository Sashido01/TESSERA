# Инвентаризация worktrees — кандидат RW05

[**Русский — оригинал**](WORKTREE_INVENTORY.md) | [English — перевод](WORKTREE_INVENTORY.en.md)

`python scripts/worktree_inventory.py --first <capture1.bin> --second <capture2.bin> --branch refs/heads/example` сравнивает два явно переданных бинарных вывода `git worktree list --porcelain -z`. Git, сеть, проверяемые worktrees и репозиторий не открывает. Получай снимки отдельными разрешёнными командами в выбранном доверенном Git, проверяй exit code и сохраняй только stdout с NUL-разделителями (не текстовое перекодирование). Не загружай вывод, содержащий пути или причины lock, в публичный репозиторий. Не используй для получения снимков неподтверждённый Git-контекст #81.

Ограничения: 2 MiB на снимок, 2000 записей, 100 явно указанных ASCII refs/heads/...; имена проверяются в пределах формата, это не полная реализация check-ref-format. Проверяются NUL framing, дубликаты путей и атрибутов, неизвестные атрибуты, допустимые HEAD и состояние bare/branch/detached, флаги locked/prunable; пути и причины остаются непрозрачными байтами. Дубликаты занятости одной ветки учитываются, не схлопываются. Сравниваются точные байты, перестановка записей считается STALE. Код 0 — OBSERVED, 1 — STALE, 2 — ошибочный ввод. Вывод включает счётчики состояний и совпадений по порядковому номеру запрошенной ветки, без путей, OID, имён refs и причин. Счётчики locked/prunable/detached могут пересекаться.

Совпадение снимков не удостоверяет их происхождение, полноту, момент получения или физическую идентичность путей. Разные имена файлов не доказывают независимость наблюдений. local_occupancy_now и snapshot_authenticity всегда NOT_VERIFIED, deletion_authorized всегда false. Даже 0 совпадений не разрешает удаление: отдельно проверить SHA, сохранность изменений после squash, отсутствие открытого PR, незакоммиченные файлы, активных исполнителей, локальные worktrees, разрешение и свежесть. Не удалять worktree по prunable. Не выполнять команды автоматически. Снимки должны быть обычными доверенными файлами; защита от подмены/спецфайлов и гонок не гарантируется.

12/12 тестов Linux на Git 2.47.3: синтетические записи и реальный временный Git с unborn, detached и locked; Git blobs проверенного скрипта и теста совпали с опубликованными. Полный CI, Windows и реальные проекты NOT_VERIFIED для кандидата. Дальнейшие шаги RW05: проверка эквивалентности принятого результата, точных refs и открытых PR, согласованная политика удаления; без автоматического удаления.
