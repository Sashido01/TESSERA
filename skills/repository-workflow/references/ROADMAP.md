| Этап | Содержание | Статус |
|---|---|---|
| RW00 | Исследование Git/GitHub, worktrees, CI, координации | PARTIAL — источники и локальные пробы |
| RW01 | Переносимая методология, локальный планировщик, контроль долга | PARTIAL — 0.0.1 принят в каталоге v0.0.69; 0.0.2 кандидат, реальный агент открыт |
| RW02 | Локальная приёмка на Windows/Linux, реальные агенты | NOT_VERIFIED |
| RW03 | Нативный GitHub профиль, PR/CI/Rulesets, зависимости Issues | NOT_STARTED |

Не создавать отдельный сервер, обязательную БД, новую очередь GitHub или зависимость от платных API без подтверждённой необходимости.

Кандидат 0.0.2: четыре новых регрессии планировщика, Unicode NFC, имена Windows, JSON и линейный обход DAG. 17/17 локальных Linux-тестов. Полный CI, реальные RW01–RW20 и Windows требуют отдельной приёмки. Добавлен независимый локальный preflight.
