# Технический долг и чистота репозитория

[**Русский — оригинал**](DEBT.md) | [English — перевод](DEBT.en.md)

Проверяй на старте каждого рабочего цикла, после слияния/релиза и перед итогом. Отделяй активную работу, реальные дефекты, долг, принятые риски и незавершённые требования. Нулевая численность Issues или веток не является самостоятельной целью.

| Область | Проверка |
|---|---|
| Задачи | Просроченные/потерянные, зависимые, дубли, ложные COMPLETE, критерии |
| Ветки | Активная цель, PR, последний коммит, подтверждённое принятие, уникальная работа |
| Worktrees | Активные исполнители, незакоммиченные данные, блокировки, сохранность |
| PR | Конфликты, устаревшая база, результаты CI, дубли, незавершённые обсуждения |
| Actions | Очереди, ошибки, отмены, тайм-ауты, пропущенные проверки, точный SHA, медленные stages |
| Релизы | VERSION/CHANGELOG, отсутствующий/неверный тег, защита, артефакты |
| Код и тесты | Заглушки, TODO с контекстом, пропущенные регрессии, слабые проверки, дубли |
| Зависимости | Advisory, лицензии, обновления, поддержка, применимость |
| Документы | Статусы, противоречия, устаревшие инструкции, ручные задачи |
| Ресурсы | Логи, временные каталоги и кеши: оценка, безопасная очистка по политике |

Для каждой находки: ID, источник, наблюдение, последствия, приоритет, зависимость, критерий закрытия, статус, доказательство, следующий шаг. Используй Project Audit при наличии для глубокого анализа, но не требуй его для базовой гигиены. Независимую работу продолжай, пока блокер исправляется. После исправления повтори соответствующий тест и обнови исходную запись. Закрывай Issues только при подтверждённом результате или явно согласованной отмене/дубликате со ссылкой; не маскируй незавершённый долг. Удаляй лишь слитую/подтверждённо сохранённую и неиспользуемую ветку с разрешением, не полагайся на возраст или только ancestry после squash. Не удаляй чужие worktrees, пользовательские файлы, теги и историю.

## Нативная сверка (только чтение)

В доверенном локальном репозитории:
```bash
git status --short --branch
git branch -vv
git worktree list --porcelain
git tag --list
git remote
```
GitHub-профиль — только при наличии выбранного и разрешённого remote:
```bash
gh issue list --state open --limit 100
gh pr list --state open --limit 100
gh run list --limit 30
gh run view <run-id>
```
Лимиты списков означают выборку; для полного аудита обрабатывай все страницы API. Сверяй точные SHA, workflow, attempts и обязательные jobs; старый failed run после успешного исправления той же задачи — историческое доказательство, не открытая задача. Не удаляй исторические запуски. Если нет remote или gh, продолжай локально. Не публикуй вывод без проверки секретов и приватных путей. Это команды для исполнителя, не автоматический сканер.

Для приватной сверки двух явно предоставленных бинарных снимков `git worktree list --porcelain -z` опционально используй [Worktree Inventory](WORKTREE_INVENTORY.md). OBSERVED не доказывает текущую занятость, ноль совпадений не разрешает удаление. При STALE/ошибке повторно обследуй, не удаляй. Не публикуй исходные снимки.
