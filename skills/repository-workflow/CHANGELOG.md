## 0.0.3 — Сверять снимки worktrees перед закрытием долга

- Опциональный read-only Worktree Inventory: два бинарных снимка, bounded parse, формат refs и SHA, счётчики branch/head/detached, проверка distinct file identities. STALE при расхождении, никогда не разрешает удаление, подлинность/текущая занятость NOT_VERIFIED.
- 21/21 изолированных Linux-тестов PASS, actual Git fixture, небезопасный Git-контекст отклоняется до мутаций. Полный CI/Windows и реальные агенты требуют приёмки.

## 0.0.2 — Уточнить область планировщика

Планировщик нормализует Unicode-области через casefold + NFC, отклоняет зарезервированные имена устройств Windows и повторяющиеся JSON-ключи, а цикл зависимостей проверяет за O(V+E). Добавлены проверки Unicode-конфликтов, путей с зарезервированными именами, длинной цепочки и цикла. Windows 11 / Python 3.14.3: 17/17 PASS. Планировщик остаётся рекомендацией по снимку и не резервирует ресурсы атомарно; применение навыка агентом NOT_VERIFIED.

## 0.0.1 — Первый кандидат

- Профили LOCAL/GITHUB, планирование независимой работы, безопасная интеграция, контроль долга, CI-производительность и опциональный локальный планировщик. Реальные агентные испытания и самостоятельный релиз открыты.
