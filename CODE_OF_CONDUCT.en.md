# Community guidelines

[Русский — основной язык](CODE_OF_CONDUCT.md) | **English — translation**

Respectful technical discussion is welcome in TESSERA. Insults, harassment, threats, and disclosure of personal information are not allowed.

Criticize concrete decisions and explain your reasoning. Do not present speculation as verified fact. When disagreements arise, use GitHub's moderation mechanisms; for private matters, contact the repository owner through an appropriate GitHub channel.

The repository owner may hide or remove content that violates these rules.
