# T12.02.01 — локальные статические проверки и профили NVIDIA

[**Русский — оригинал**](NVIDIA_STATIC_REVIEW.md) | [English — перевод](NVIDIA_STATIC_REVIEW.en.md)

Используется закреплённый NVIDIA SkillEvaluator 1.2.0 из [T12.01](NVIDIA_TIER1.md), без дополнительных пакетов. Официальный [исходник](https://github.com/NVIDIA/SkillEvaluator/tree/5625c2534bf266f810aea489ffbe69da0bb2645e) и профили зафиксированы по commit. Никаких LLM, Tier 2/3, общего validate, автозагрузки сканеров и запуска агентов. PII, license, unicode, lint запускаются явной командой tier1 --no-llm --checks pii,license,unicode,lint; проверяются завершённость, покрытие PII/Unicode, согласованность JSON/exit code. Отрицательный тест Unicode содержит синтетический BiDi override и обязан дать HIGH/FAIL. Проверка PII без достоверной личности автора/submitter ограничена: персональные домашние пути не гарантированно распознаются. Проверка лицензии навыка не является аудитом лицензий всех зависимостей; отсутствующая декларация не считается подтверждённой лицензией даже при advisory PASS.

## Качество русского оригинала

Сохраняется исходная оценка NVIDIA и все замечания. Второй прогон использует tools/nvidia-quality-ru.json (JSON является подмножеством YAML): добавлены русские альтернативы заголовков требований, ограничений и устранения неполадок, а также русские термины ошибок и проверки; исходные английские термины, 5 баллов на заголовок и вес reliability 25% не изменены. Сопоставляются все четыре измерения и взвешенная сумма. Никакого изменения порога 70, отключения правил или правки SKILL.md ради баллов. Схема, hardcoded английские эвристики и реальные проблемы документации остаются предметом ручного анализа. Неизвестное замечание сохраняется как UNCLASSIFIED; сырые тексты, пути и совпавшие PII в CI не выводятся.

## Совместимость

Реальный harness-check работает только по статическим профилям вендора, **не запускает ни одного клиента**. Проверяются копии одного и того же навыка в изолированных модельных каталогах: Codex (.agents/skills), Claude Code (.claude/skills), Copilot CLI (.github/skills), Hermes (.hermes/skills), OpenClaw (skills), OpenCode (.opencode/skills). Codex дополнительно — custom provider и явная активация; отрицательный тест Codex на неправильном корне .claude/skills. JSON сохраняет статусы loads/degraded/not_loaded, версии и даты профилей и идентификаторы ограничений. DeepSeek Harness отсутствует в upstream профилях 1.2.0; нужен отдельный проектный тест. Реальное обнаружение, загрузка, исполнение и hooks во всех агентах NOT_VERIFIED.

## Приёмка

Все данные временные, домашняя папка изолирована, ключи API не передаются. Время обзора измеряется монотонными часами; это не расчёт фактического биллинга. ### Статические проверки

- Unicode: PASSED, 16 файлов, 0 замечаний, негативный BiDi тест PASS.
- PII: PASSED, 16 файлов, 1 medium ip_addresses, 2 предупреждения. В исходниках всех 16 файлов обнаружена одна строка формата IPv4: отрицательный тест версии в tests/test_next_version.py:67, совпадающий с регулярным выражением NVIDIA. Это сильное основание считать замечание ложным, но местоположение из сырого JSON не проверено отдельно. Не подавлять правило. Покрытие персональных домашних путей NOT_VERIFIED.
- License: PASSED с предупреждением, license_status=not_detected. MIT в LICENSE корня репозитория подтверждён; отдельный навык не имеет декларации/файла лицензии, поэтому изолированная установка требует явной переносимой лицензии. Не считать PASS подтверждением лицензии.
- SCRIPT_LINT: PASSED, два low magic_numbers. Не считать это полным линтингом или проверкой всех языков, raw locations не сохранены; необходим ручной разбор, а не механическая замена констант.
