Investigate new queue, parallel steps, Actions lockfiles and event listening on actual account; do not assume availability.
- Analogues: [Superpowers](https://github.com/obra/superpowers) — worktree, TDD, task separation; [Spec Kit](https://github.com/github/spec-kit) — specifications and dependencies; [Beads](https://github.com/gastownhall/beads) — ready work; [Worktrunk](https://github.com/max-sixty/worktrunk) — worktrees; Git Workflow Skill, Agent Collab, Task Orchestrator, Vibe Kanban — candidates. - [Effective Strategies for Asynchronous Software Engineering Agents / CAID](https://arxiv.org/abs/2603.21489), [AsynCodeBench](https://arxiv.org/abs/2609.32662), [ParallACT](https://arxiv.org/abs/2611.00314): scopes, dependencies, coordination and semantic conflicts. RepoReason/RepoProbe, TraceLLM/TraceDev, Graph2Env — further review. Seven logical graphs: structure, semantics, dependencies, requirements, checks, history, evidence; no mandatory graph database.
- [VerifierBench](https://arxiv.org/abs/2610.28679), SWE-ABS, CR-Bench-v2, ReviewBench: verifier quality, negative controls, separate precision/recall, evaluate novel findings. Property/metamorphic/differential/fault injection/fuzz/mutation/contract/model checking/symbolic execution/slicing — optional profiles, Hypothesis, fast-check, cargo-fuzz, Schemathesis, Pact, Z3, TLA+/TLC.
- Looping Is Not Reliability, Graph2Env, SpecBench: bind results to snapshot, environment and configuration; identify workflow weaknesses. DELTA only with sufficient dependency map; one commit SHA is insufficient for a dirty tree. Historical CI does not verify a new snapshot.
- [SkillsBench](https://www.skillsbench.ai/) — compare with/without skill; NVIDIA Tier 1 static-only; Runtime Skill Audit and MalSkillBench — actual behavior research. Actual behavior evals required; no Tier 2/3 or mandatory paid APIs. Metrics: recall, precision, false COMPLETE, evidence accuracy, coverage, stale evidence, source integrity, resume, tokens and time. No opaque aggregate score.

Next candidate: bounded chunks, framing/OID/size/EOF and deadline validation; retain inventory recheck and host/container parity. Separate finding identity and evidence freshness; matching is not revalidation. DELTA must invalidate changed dependencies, config, analyzer version and incomplete scope; absence is not proof of remediation. [Codex Security workflow-routing evals](https://github.com/openai/codex-security/blob/main/evals/workflow-routing/README.md) illustrate fresh-session skill loading tests; compare with no-skill fixtures and record false activation and actions, not just model answers.
- **Repository Workflow:** [git worktree](https://git-scm.com/docs/git-worktree) supports machine-readable list --porcelain, lock and prune dry-run. Include in future read-only inventory; do not delete based solely on ancestry after squash; compare accepted blobs/patch, open PRs and local use. [Git refs API](https://docs.github.com/en/rest/git/refs?apiVersion=2022-11-28) documents ref deletion; current connector lacks DELETE, owner action after worktree check. Do not delete Actions history for cosmetic counts.

Results: primary sources reviewed; batch prototype and isolated diagnostics checks executed; no external dependencies, host configuration or security gates changed. Full CI and product acceptance required.
