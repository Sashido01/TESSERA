## Repository Workflow
- GitHub Flow + short-lived branches and trunk-based integration; stacked PR only for actual dependencies, no permanent develop. Monorepo with independent versions. Worktrees separate files but not all refs/resources: [Git worktree](https://git-scm.com/docs/git-worktree).
- Native [Issue dependencies](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-issue-dependencies), [merge queue](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/configuring-pull-request-merges/managing-a-merge-queue?apiVersion=2022-11-28) (organization), [required checks](https://docs.github.com/en/pull-requests/how-tos/merge-and-close-pull-requests/troubleshooting-required-status-checks?apiVersion=2022-11-28), [gh pr merge](https://cli.github.com/manual/gh_pr_merge), [concurrency](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/control-workflow-concurrency), [dependency caching](https://docs.github.com/en/actions/concepts/workflows-and-actions/dependency-caching), [reusable workflows](https://docs.github.com/en/actions/concepts/workflows-and-actions/reusing-workflow-configurations). Investigate new queue, parallel steps, Actions lockfiles and event listening on actual account; do not assume availability.
- Analogues: [Superpowers](https://github.com/obra/superpowers) — worktree, TDD, task separation; [Spec Kit](https://github.com/github/spec-kit) — specifications and dependencies; [Beads](https://github.com/gastownhall/beads) — ready work; [Worktrunk](https://github.com/max-sixty/worktrunk) — worktrees; Git Workflow Skill, Agent Collab, Task Orchestrator, Vibe Kanban — candidates. No mandatory installation.
- [Changesets](https://github.com/changesets/changesets) and [Release Please](https://github.com/googleapis/release-please) — separate change intent from release; [Nx affected](https://nx.dev/docs/features/ci-features/affected) — impact analysis. Keep TESSERA microversion policy and minimal tools.
- [Effective Strategies for Asynchronous Software Engineering Agents / CAID](https://arxiv.org/abs/2603.21489), [AsynCodeBench](https://arxiv.org/abs/2609.32662), [ParallACT](https://arxiv.org/abs/2611.00314): scopes, dependencies, coordination and semantic conflicts. NP-Bench — source to recheck. Do not transfer experimental figures to TESSERA without benchmarks.
- Local Git probes (25 November 2026, 5/5 in earlier execution): early shared VERSION conflicts; late assignment and serial squash/tag work; textually clean merge can break behavior; worktrees separate files but share tags; atomic push of conflicting tags to a bare remote rejects the entire set. Live GitHub atomic push/Rulesets not verified.

## Project Audit
- Analogues project-audit-skill, Codebase Audit, Repo Audit, All Audits, OpenAudit: method, inventory, independent challenge, modularity and reports. No mandatory copying of third-party skills.
- Inventory/retrieval: scc, ripgrep, Tree-sitter, ast-grep, Repomix, Ctags, SCIP/LSP; architecture: CodeScene/Code Maat, SonarQube, ArchUnit, dependency-cruiser, Import Linter, Madge, Joern, CodeQL; language profiles Ruff/mypy/Pyright, Clippy, ESLint/Biome, Staticcheck, clang-tidy, PMD, Roslyn, ShellCheck. Prefer native tools; others optional.
- Security: Gitleaks, Bandit, Semgrep, Govulncheck, OSV, Syft/Grype, Trivy, OpenSSF Scorecard; ISO/IEC 25010 quality model, NASA bidirectional traceability, NIST SSDF; no certification claim. Dynamic checks and indirect prompt injection protection. Tool output is not proof of CVE applicability.
- [RIG](https://arxiv.org/abs/2601.10112), [How Should Agents See Code?](https://arxiv.org/abs/2611.07286), [Agent Retrieval Bench](https://arxiv.org/abs/2607.24882): component/test maps, varied code views, adaptive context retrieval and no relevant context. RepoReason/RepoProbe, TraceLLM/TraceDev, Graph2Env — further review. Seven logical graphs: structure, semantics, dependencies, requirements, checks, history, evidence; no mandatory graph database.
- [VerifierBench](https://arxiv.org/abs/2610.28679), SWE-ABS, CR-Bench-v2, ReviewBench: verifier quality, negative controls, separate precision/recall, evaluate novel findings. Property/metamorphic/differential/fault injection/fuzz/mutation/contract/model checking/symbolic execution/slicing — optional profiles, Hypothesis, fast-check, cargo-fuzz, Schemathesis, Pact, Z3, TLA+/TLC.
- Looping Is Not Reliability, Graph2Env, SpecBench: bind results to snapshot, environment and configuration; identify workflow weaknesses. DELTA only with sufficient dependency map; one commit SHA is insufficient for a dirty tree. Historical CI does not verify a new snapshot.
- [SkillsBench](https://www.skillsbench.ai/) — compare with/without skill; NVIDIA Tier 1 static-only; Runtime Skill Audit and MalSkillBench — actual behavior research. Actual behavior evals required; no Tier 2/3 or mandatory paid APIs. Metrics: recall, precision, false COMPLETE, evidence accuracy, coverage, stale evidence, source integrity, resume, tokens and time. No opaque aggregate score.
