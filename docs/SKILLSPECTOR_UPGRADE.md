## T12.03.05 — локализация замечаний (кандидат)

Закреплённая реализация `Finding.to_dict()` в `src/skillspector/models.py` содержит первичное поле `location` и отдельный список `occurrences`. Обёртка теперь публикует только проверенные первичные координаты: правило, уровень, относительный путь из инвентаря, начальную и необязательную конечную строку. Неизвестные, абсолютные или некорректные пути/координаты не выводятся; их количество отражается в `primary_locations_unresolved`. После 1000 строк увеличивается `primary_locations_omitted`. Общие счётчики замечаний не изменяются. Предел по байтам — верхняя граница числа строк, не подтверждение точного совпадения строки. Фрагменты кода, сообщения, контекст и occurrences не выводятся. Это диагностическая подготовка, не исправление замечаний; живой CI необходим.

## TD13 — предварительная сверка wheel с исходным деревом

Кандидат `tools/check_skillspector_wheel.py`: только чтение архива без установки, извлечения или импорта. Закреплены SHA-256 и размер 1 342 092 байта официального GitHub release asset 2.13.7; Git tree commit c323ad4c43e3c8f2de051572cc25b2711d11e648 содержит 169 файлов src/skillspector (5 201 401 байт) и два license/notice файла. Проверяется точное соответствие каждого файла пакета Git blob, отсутствующие/лишние файлы, RECORD SHA-256/размер/охват, metadata и единственный ожидаемый console entrypoint. Не допускаются traversal, ссылки, дубликаты имён без учёта регистра, незаявленные startup/.data файлы. Лимиты 512 записей, 8 MiB на файл и 16 MiB суммарно. 9/9 синтетических тестов Linux Python 3.13.5 PASS. Реальные байты release wheel ещё не получены; WHEEL_PROVENANCE NOT_VERIFIED, не считать доказанной безопасность или отсутствие MAL-2026-6561. Без обновления main или ослабления существующего gate.
