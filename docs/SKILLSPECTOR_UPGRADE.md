## T12.03.05 — локализация замечаний (кандидат)

Закреплённая реализация `Finding.to_dict()` в `src/skillspector/models.py` содержит первичное поле `location` и отдельный список `occurrences`. Обёртка теперь публикует только проверенные первичные координаты: правило, уровень, относительный путь из инвентаря, начальную и необязательную конечную строку. Неизвестные, абсолютные или некорректные пути/координаты не выводятся; их количество отражается в `primary_locations_unresolved`. После 1000 строк увеличивается `primary_locations_omitted`. Общие счётчики замечаний не изменяются. Предел по байтам — верхняя граница числа строк, не подтверждение точного совпадения строки. Фрагменты кода, сообщения, контекст и occurrences не выводятся. Это диагностическая подготовка, не исправление замечаний; живой CI необходим.

## TD13 — предварительная сверка wheel с исходным деревом

`tools/check_skillspector_wheel.py` проверяет ZIP без установки, извлечения файлов или импорта. Официальная [страница NVIDIA v2.13.7](https://github.com/NVIDIA/SkillSpector/releases/tag/v2.13.7) показывает подписанный и проверенный commit `c323ad4c43e3c8f2de051572cc25b2711d11e648`; GitHub Release API указывает wheel размером 1 342 092 байта и SHA-256 `e2356aa11f0d484f789543f25da6208fe2408641c8b16e7b59bc6600c5c39ffb`. Эти данные совпали с независимо скачанными байтами. На Windows 11 / Python 3.14.3 проверка сопоставила 169 файлов пакета с Git blobs указанного исходного commit; 174 wheel entries и 174 строки RECORD учтены, RECORD, метаданные, license и console entry point прошли. Итог: `source_blob_match=PASS`, `record=PASS`, `execution=NOT_RUN`; 9/9 тестов checker прошли.

[OSV MAL-2026-6561](https://osv.dev/vulnerability/MAL-2026-6561) включает версию 2.13.7 пакета `skillspector` из PyPI и описывает подложенный telemetry-модуль. Проверенный GitHub wheel не содержит лишнего модуля и его файлы совпадают с официальным исходным деревом; это различает два источника распространения, но не доказывает общую безопасность сканера или поведения при запуске.

Workflow-кандидат скачивает asset по закреплённому HTTPS URL, выполняет preflight до установки и затем передаёт pip тот же локальный `file://` wheel с `--require-hashes`; удалённый URL пакета не используется как fallback. Локальные Windows workflow-security tests — 39 PASS, 1 Linux-only SKIP; отрицательные варианты удалённого gate, позднего порядка, удалённого wheel и разрешённых посторонних redirect блокируются. Реальный PR/main CI этого нового workflow ещё обязателен; TD13 и Issue #76 остаются PARTIAL до его завершения.
