## Первый кандидат T19.02

Перенос пары host/Docker Gitleaks history в независимую job history_checks. Остальные прежние проверки остаются в catalog_checks. Обе запускаются на том же GitHub SHA с полной историей, без persist credentials, с прежними pinned Actions и обязательным Docker preflight. Образ и бинарник закреплены прежними хешами. Не использовать кеши отчётов и не исключать blobs. Host/container сравнивают один снимок достижимых локальных refs внутри history job; неполученные remote refs не покрыты. Дублируется только минимальная подготовка, не сам аудит.

Обязательный check сохраняет имя validate: всегда запускается и требует result=success от обеих jobs. Отказ, отмена и пропуск обязательной группы не удовлетворяют gate. tag_microversion сохраняет needs: validate. Проверки существующего workflow и закреплённых Actions актуализированы, добавлены регрессионные сценарии. Результат CI нового кандидата пока NOT_VERIFIED. Не назначать корневую микроверсию до интеграционного слота.

Baseline main 45568501762: 943 с; история 488 с. PR 45569400436: 700 с; история 345 с. Идеальный расчёт без дополнительных расходов — max(488,455)=488 с и max(345,355)=355 с; не прогноз фактической скорости. Два runner могут ждать очередь, подготовка и рост каталога влияют на время. Приёмка: сравнить реальные p50/p95 и очередь/runner-minutes по сопоставимым запускам, подтвердить обязательность обеих групп и тег. Если нет выигрыша — измерить причину, не усложнять систему ради количества jobs.
