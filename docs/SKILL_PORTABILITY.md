# T12.03.01 — переносимость лицензии и документации навыка

[**Русский — оригинал**](SKILL_PORTABILITY.md) | [English — перевод](SKILL_PORTABILITY.en.md)

В изолированной проверке SkillSpector 2.13.6 обнаружены четыре reference_missing ([CI 45370414762](https://github.com/Sashido01/TESSERA/actions/runs/45370414762)); в документации действительно были четыре ссылки за пределы каталога навыка. NVIDIA License Compliance ранее возвращал not_detected. Это подтверждённые недостатки переносимости.

Исправление: отдельный LICENSE.txt с точными байтами корневого MIT, license: MIT в каноническом frontmatter, автономные инструкции RU/EN, внешние ссылки на неизменяемый v0.0.30 только для дополнительного чтения. Сборщик ZIP включает отдельную лицензию. Регрессии проверяют её наличие и байты в ZIP, отказ при symlink, сохранение лицензии при реальном gh skill install --from-local, отказ при её потере и разрешимость простых относительных Markdown-ссылок только в составе пакета (не общий Markdown-парсер, не проверка доступности внешних URL или фрагментов).

Не отключены правила сканеров, не изменены пороги и веса. Не заявляется улучшение оценки без нового CI. Сценарии реальных агентных клиентов, доказательство полноценной юридической совместимости, риск MP3/RA1 и остальные замечания остаются отдельными задачами.

Статус: реализация подготовлена; реальная приёмка CI обязательна.

Канонический SKILL.md сокращён с 11279 до 8876 байт UTF-8, ниже рекомендации закреплённого статического профиля custom provider в 10000 байт. Политика микроверсий, обязательность тега, явные полномочия, координация и отчёт сохранены; выделены требования, таблица скриптов, примеры и ошибки. Описание начинается с назначения, экспериментальные широкие разрешения не добавлены. Регрессия контролирует лимит и обязательные маркеры; реальные клиенты NOT_VERIFIED.
