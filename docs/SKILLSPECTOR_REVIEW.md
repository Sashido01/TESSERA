## Координаты всех сообщённых HIGH/CRITICAL occurrences — кандидат

Закреплённая модель [Finding 2.13.7](https://github.com/NVIDIA/SkillSpector/blob/v2.13.7/src/skillspector/models.py) сериализует occurrences как список с file/start_line/end_line; пустой внутренний список получает первичное место. Первичный finding может группировать несколько occurrences. Новый ограниченный вывод high_occurrence_locations использует только допустимый путь из фактической component inventory и проверенные числовые координаты, severity и rule; без snippets, raw URLs, fingerprints, сообщений, provenance или иных metadata. Отдельно считаются группы без списка, сообщённые occurrences, unresolved и omitted; лимит 1000 строк, при достижении оставшиеся считаются omitted. Это не доказательство полноты внутренней дедупликации, не автоматический triage и не изменение findings/score/suppression. Два новых regression methods, живой CI обязателен. Использовать для G09: проверить каждый сообщённый HIGH/CRITICAL occurrence и сопоставить с точным Git snapshot, не принимать вывод о безопасности по одному primary location.
