# T12.02.02.01 — прямой статический обзор Python

[**Русский — оригинал**](BANDIT_REVIEW.md) | [English — перевод](BANDIT_REVIEW.en.md)

Bandit 1.9.4 уже закреплён в tools/nvidia-tier1-requirements.txt по SHA-256. [Upstream](https://github.com/PyCQA/bandit), Apache-2.0. Не добавляются новые зависимости, платные API, LLM или Tier 2/3. Прямой запуск Bandit не является приёмкой объединённого NVIDIA code-integrity: остальные сканеры и CVE остаются отдельными задачами.

## Контракт

- Сканируется снимок всех отслеживаемых Git файлов Python текущего рабочего дерева (в CI — checkout проверяемого коммита); тесты отделены от runtime в агрегате. Никакие файлы цели не исполняются.
- Выделенный временный каталог, окружение без наследуемых API-ключей и токенов; конфигурация цели не переносится. Проверяются версия CLI, фактический перечень файлов в JSON, ошибки, коды возврата и неизменность исходников.
- Используется --ignore-nosec, без исключения правил, baseline и --exit-zero. Синтетические положительный и отрицательный сценарии обязательны: B307 должен обнаруживаться даже с nosec.
- Код завершения 1 с корректными findings не скрывается: это отчёт о замечаниях, не чистая проверка. Неполное сканирование, отсутствующий JSON, ошибка формата, тайм-аут или несовпадение покрытия блокируют CI.
- В логах только числа, коды правил, severity/confidence, категория runtime/tests и время. Сырые строки, пути, сообщения и отчёты не публикуются. Анализ статический, изоляция окружения не является сетевым sandbox.

## Запуск и приёмка

Используйте уже установленное хешированное окружение Tier 1; команда: `python tools/check_bandit_review.py --repo . --cli <путь-к-bandit>`. Маркер BANDIT_REVIEW_EXECUTION_PASS означает выполнение контракта, а не отсутствие уязвимостей. Замечания требуют ручного анализа до введения политики блокировки; отсутствие замечаний не доказывает безопасность.

Статус T12.02.02.01 — COMPLETE в границах выполнения прямого обзора. T12.02.02 и T12 — PARTIAL. Дальше: Gitleaks, SkillSpector, CVE и лицензии зависимостей; не разрешать автоматическую установку внешних сканеров без отдельного аудита.
