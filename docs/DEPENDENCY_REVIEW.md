# T12.02.02.04 — аудит зависимостей и лицензий

[**Русский — оригинал**](DEPENDENCY_REVIEW.md) | [English — перевод](DEPENDENCY_REVIEW.en.md)

Используются только публичные идентификаторы пакетов и точные версии. [OSV querybatch](https://google.github.io/osv.dev/post-v1-querybatch/) — бесплатный API без LLM или токена, запросы POST на фиксированный HTTPS endpoint, строгая проверка размеров и полноты ответов с pagination. Отрицательный контроль проверяет известные advisories старой версии requests без установки пакета. Не отправляются исходники, Git-данные владельца или ключи. Сетевая/структурная ошибка блокирует проверку; отсутствие записей не гарантирует отсутствие уязвимостей.

Python: отдельный инвентарь всех установленных дистрибутивов из закреплённых окружений NVIDIA Tier 1 и SkillSpector; для skills-ref — точное соответствие активным хешированным pins. Отдельно запрашиваются upstream commit SHA. Метаданные License-Expression, известные legacy-декларации, classifiers и наличие записей license files — доказательства уровня метаданных, не юридическая экспертиза совместимости.

Go: для проверенных по SHA-256 gh 2.105.0 и Gitleaks 8.30.1 читается build info командой go version -m (сканируемые бинарники не исполняются), проверяются корневой модуль, точные версии зависимостей, замены и доступная VCS-ревизия. OSV запрашивается по фактическим Go-модулям, stdlib/toolchain и закреплённым upstream SHA. Лицензии Go-модулей — внешние метаданные [deps.dev API v3](https://docs.deps.dev/api/v3/), источник данных CC-BY 4.0; пустой/недоступный результат явно UNKNOWN/NOT_VERIFIED. Go parser — предустановленный инструмент CI, версия записывается; это не дополнительная runtime-зависимость навыков.

Находки advisory до анализа; нельзя выдавать наличие OSV ID за доказанную достижимость уязвимого кода, а отсутствие ID за безопасность. Полный анализ лицензий, нативные не-Go компоненты и уязвимости вне баз остаются NOT_VERIFIED. Реальная приёмка обязательна; никаких платных API, Tier 2/3 или автоматического исправления зависимостей.

Метаданные Go могут содержать зависимость `(devel)`. При наличии замены с точной версией проверяется замена; иначе модуль остаётся явно непроверенным. Запрос по угаданной версии запрещён. Иные неизвестные форматы версии блокируют проверку. Успешное исполнение с непроверенными модулями означает PARTIAL покрытия, а не полную проверку CVE.

Go-аудит пока BLOCKED на полноте метаданных; уточняются отсутствие корня, отсутствие зависимостей и превышение лимита без вывода локальных путей.

CI 45373906360: gh — одна строка mod, 154 dep; Gitleaks — ноль mod, 66 dep, одна без версии. В upstream v8.30.1 .goreleaser.yml сборка main.go; синтетическая локальная сборка Go 1.23.2 воспроизвела path command-line-arguments, отсутствие mod и корневую dep (devel). Исключение ограничено закреплённым архивом Gitleaks, точным entrypoint и корневой зависимостью. Проверка независимо сверяет SHA-256 обоих архивов и байты бинарника с членом архива до чтения метаданных. Корневая версия берётся из подтверждённых метаданных выпуска архива, а не выдаётся за встроенную в бинарник. Прочие зависимости без версии остаются PARTIAL. Реальный CI необходим.
