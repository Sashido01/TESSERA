# Безопасность

## Поддерживаемые версии

Это ранняя библиотека Agent Skills. Отдельная долгосрочная матрица поддержки пока не объявлена. Проверяйте актуальную ветку и состояние конкретного навыка.

## Как сообщать о проблеме

Если на GitHub включено приватное сообщение об уязвимости (Private vulnerability reporting), используйте раздел **Security → Report a vulnerability**. Если этот механизм недоступен, не публикуйте эксплуатационные подробности, токены или персональные данные в открытых Issues; свяжитесь с владельцем репозитория подходящим приватным способом.

## Границы доверия

- Инструкция `SKILL.md` не является механизмом принудительного контроля действий агента.
- Не доверяйте автоматически скриптам и командам из неизвестных навыков.
- Перед установкой проверяйте файлы и разрешения, особенно для навыков, которые выполняют Git-операции или работают с сетью.
- Расчёт версии сам по себе не подтверждает успешные тесты, коммит, тег или готовый релиз.
- При изменениях не публикуйте секреты, приватные журналы, файлы авторизации и конфигурации других проектов.
