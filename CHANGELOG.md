# История изменений TESSERA

[**Русский — оригинал**](CHANGELOG.md) | [English — перевод](CHANGELOG.en.md)

Здесь фиксируются изменения **общего каталога**. Истории отдельных навыков могут вестись в их собственных папках.

## 0.0.2 — Навык стал переносимым между агентами

- Убрана привязка Microversion Release только к Harness: описаны подключения Codex, Claude Code, Hermes и других совместимых систем.
- Добавлен безопасный локальный установщик с предварительным просмотром и запретом перезаписи уже установленного навыка.
- Для каждого релиза закреплён обязательный аннотированный Git-тег с проверкой типа, описания и целевого коммита.
- Добавлены скрипт проверки/создания релизного тега и автоматические тесты на пропущенные, легковесные и неверно привязанные теги.
- Русская документация обновлена как оригинал, английская — как полный перевод. Работа в конкретных установках агентов остаётся NOT_VERIFIED.

## 0.0.1 — Введена обязательная микроверсионность каталога

- Для TESSERA закреплены те же правила, что и для Microversion Release: шаг PATCH+1, релизные рубежи `.99`, продолжение `.100+` при незавершённой задаче.
- Добавлен единый источник версии `VERSION` и проверка переходов при каждом изменении.
- Настроено создание аннотированного Git-тега после успешной проверки изменений в `main`.
- Уточнены русские и английские инструкции по разработке и выпуску версий.
- Ранее добавленные английские переводы и языковая политика сохраняются; опубликованная история не переписывается.

**Ограничение:** создание тега зависит от прав GitHub Actions. Настоящие сборочные артефакты и GitHub Release не создаются автоматически.

## 0.0.0 — Основа библиотеки (23.11.2026)

- Подготовлен публичный каталог переносимых Agent Skills.
- Добавлен первый навык Microversion Release с правилами перехода от рабочих микроверсий к релизным рубежам.
- Добавлены требования к естественным русским описаниям коммитов, тегов и релизов.
- Подготовлены тесты расчёта версий и проверки структуры каталога.
- Описаны правила участия, безопасности и дорожная карта.

**Статус:** стартовое состояние репозитория. Автоматическая интеграция с установленным Harness, публикация сборок и GitHub Release не подтверждены.
