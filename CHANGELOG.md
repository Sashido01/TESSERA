# История изменений TESSERA

[**Русский — оригинал**](CHANGELOG.md) | [English — перевод](CHANGELOG.en.md)

Здесь фиксируются изменения **общего каталога**. Истории отдельных навыков могут вестись в их собственных папках.

## 0.0.5 — Усилен контроль GitHub Actions и подготовлена защита Git

- Официальные GitHub Actions закреплены за полными commit SHA, проверяющий job выполняется без сохраняемых Git-учётных данных.
- Создание аннотированного тега останавливается, если удалённая ветка `main` изменилась или не удалось проверить существующий тег.
- Добавлены статическая проверка защитных требований workflow и шесть отрицательных/положительных тестов.
- Подготовлена двуязычная инструкция включения GitHub Rulesets для ветки и тегов.
- T08 отмечен PARTIAL/BLOCKED: настройки Rulesets не применены и не подтверждены; конкурентные релизы пока не сериализованы.

## 0.0.4 — Уточнены публичные правила зависимостей

- Удалены названия исключённых сторонних решений из актуальной публичной документации и истории изменений, представленной в рабочей ветке.
- Документы теперь описывают только принятый стек: официальный GitHub CLI, минимальные собственные Python-инструменты и бесплатные проверки.
- Закреплено правило не перечислять отклонённые продукты по названиям в общедоступных материалах.
- Согласованы русские оригиналы и английские переводы без изменения исполняемых компонентов.

**Ограничение:** ранее опубликованные Git-коммиты не переписаны; старые редакции документов остаются в истории репозитория.

## 0.0.3 — Утверждена архитектура и дорожная карта развития

- Расширена единая дорожная карта этапами T08–T17 с приоритетами, зависимостями и проверяемыми критериями приёмки.
- Утверждены одно независимое ядро Release Core и небольшие адаптеры Codex, Harness, Claude Code, Hermes.
- Основным планируемым средством распространения выбран официальный GitHub CLI; Python-установщик сохранён как минимальный офлайн-резерв.
- Закреплён минимальный стек распространения через GitHub CLI и Python; NVIDIA SkillEvaluator ограничен бесплатным Tier 1 после отдельной проверки, Tier 2/3 и обязательные платные AI API запрещены.
- Запланированы эталонный валидатор Agent Skills `skills-ref` и отдельная оценка затрат/качества NVIDIA Tier 1.
- Обновлены архитектура, правила работы с репозиторием и полные английские переводы без изменения работающих скриптов.

**Статус:** изменения документации и политики. Запланированные инструменты не установлены, а межагентные интеграции не проверены.

## 0.0.2 — Навык стал переносимым между агентами

- Убрана привязка Microversion Release только к Harness: описаны подключения Codex, Claude Code, Hermes и других совместимых систем.
- Добавлен безопасный локальный установщик с предварительным просмотром и запретом перезаписи уже установленного навыка.
- Для каждого релиза закреплён обязательный аннотированный Git-тег с проверкой типа, описания и целевого коммита.
- Добавлены скрипт проверки/создания релизного тега и автоматические тесты на пропущенные, легковесные и неверно привязанные теги.
- Русская документация обновлена как оригинал, английская — как полный перевод. Работа в конкретных установках агентов остаётся NOT_VERIFIED.

## 0.0.1 — Введена обязательная микроверсионность каталога

- Для TESSERA закреплены те же правила, что и для Microversion Release: шаг PATCH+1, релизные рубежи `.99`, продолжение `.100+` при незавершённой задаче.
- Добавлен единый источник версии `VERSION` и проверка переходов при каждом изменении.
- Настроено создание аннотированного Git-тега после успешной проверки изменений в `main`.
- Уточнены русские и английские инструкции по разработке и выпуску версий.
- Ранее добавленные английские переводы и языковая политика сохраняются; опубликованная история не переписывается.

**Ограничение:** создание тега зависит от прав GitHub Actions. Настоящие сборочные артефакты и GitHub Release не создаются автоматически.

## 0.0.0 — Основа библиотеки (23.11.2026)

- Подготовлен публичный каталог переносимых Agent Skills.
- Добавлен первый навык Microversion Release с правилами перехода от рабочих микроверсий к релизным рубежам.
- Добавлены требования к естественным русским описаниям коммитов, тегов и релизов.
- Подготовлены тесты расчёта версий и проверки структуры каталога.
- Описаны правила участия, безопасности и дорожная карта.

**Статус:** стартовое состояние репозитория. Автоматическая интеграция с установленным Harness, публикация сборок и GitHub Release не подтверждены.
