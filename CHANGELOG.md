# История изменений TESSERA

[**Русский — оригинал**](CHANGELOG.md) | [English — перевод](CHANGELOG.en.md)

Здесь фиксируются изменения **общего каталога**. Истории отдельных навыков могут вестись в их собственных папках.

## 0.0.86 — Проверять точную цель и защищать Git-фикстуры

- Microversion Release 0.0.5: обязательный --expected-version в Guarded Run, schema 2; несоответствие цели блокирует до тестов, даже если версия структурно допустима. Четыре новых regression methods, включая реальный release fixture с тегом и без него.
- Microversion Release и Project Audit 0.0.6: setup старых изменяющих Git tests отклоняет наследуемые Git_* кроме pager до любых записей, два regression methods. Изолированные новые fixtures используют явный allowlist системных переменных. Production-политика неизменна.
- PR #92 CI 45852127083 5/5 PASS; SkillSpector 100% coverage, но Microversion 11 HIGH, Audit aggregate risk gate 1 HIGH, Workflow 0 HIGH. G09 открыт, результаты advisory не равны чистой безопасности. Native CI кандидата и реальная клиентская приёмка обязательны.

## 0.0.85 — Обязательная независимая проверка завершения

- Microversion Release 0.0.4: Completion Gate проверяет линейные переходы версии, changelog, точные annotated tags, чистоту и флаги индекса, повторно сверяет HEAD/refs. Базовый профиль корневых VERSION/changelog. Stop adapter запрашивает не больше одного продолжения на выбранный владельцем marker, без автоматического тегирования.
- Guarded Run запускает только явно выбранные команды владельца после --execute; независимо проверяет структуру, реальный exit агента, тесты и итоговый SHA/объекты тегов. No-op блокируется по умолчанию. Не заменяет sandbox/доказательство активации.
- 26/26 локальных тестовых методов Linux / Python 3.13.5 / Git 2.47.3 (16 Git/Stop + 10 subprocess fixture), Git blobs сверены. Полный CI и реальная клиентская приёмка обязательны.
- Владелец утвердил базовые версии всех трёх навыков, обязательное исполнение в Codex/Harness и GitHub Immutable Release с аттестованным ZIP. v0.0.84 и настройка squash-only подтверждены. #81 остаётся открытой.

## 0.0.84 — Зафиксировать обязательные проверки выпуска 0.1.0

- Release Core: обязательные CI jobs выбираются независимо от полученных API jobs. Текущий профиль требует все шесть; историческая политика TESSERA выводится из корневого VERSION точного коммита, не из версии навыка. Отсутствие групп блокирует отчёт; добавлены регрессии.
- Изолированная модель алгоритма 8/8 PASS, проверены границы исторических workflow. Полный CI кандидата обязателен.
- Подготовлены критерии G01–G12, границы продукта, инструкция владельцу, проверка происхождения ZIP и исследование Immutable Releases. Сверены точные v0.0.83/project-audit/v0.0.5 и обновлены pin пилота. #78 закрыта владельцем, #81 остаётся открытой.

## 0.0.83 — Планировать DELTA-аудит и сверить документацию

- Project Audit 0.0.5: план повторных проверок по двум явно заданным DAG; изменённые и неизвестные отпечатки инвалидируют зависимые узлы, неполный граф или изменение контекста требуют полной перепроверки. Не читает проект и не переносит PASS.
- 14/14 изолированных Linux-тестов; Git blobs исходника и теста сверены. Полный CI и реальная активация обязательны.
- TD15/#78: актуализированы RU/EN README и справочники Inventory, Git Inspector, Evidence Core, roadmap. Сверен принятый v0.0.82 и microversion-release/v0.0.3; фактическая клиентская приёмка не подменяется CI.

## 0.0.82 — Диагностировать наследуемый Git-контекст

- Microversion Release 0.0.3: диагностика имён блокирующих переменных без значений и без запуска Git; осиротевшие индексированные GIT_CONFIG_* также блокируют операции тегирования и локальной инспекции. Не удаляет настройки хоста и не разрешает обход ограничений.
- TD17/#81: четыре новых тестовых метода и расширенная негативная регрессия; полноценный CI и реальная приёмка Codex обязательны. Изолированная проверка извлечённой логики 6/6 PASS, не полный suite.
- Сверены доказательства v0.0.81; добавлены исследования Codex/Harness, безопасного batch-чтения Git, DELTA и evals. Результаты прототипа не подменяют приёмку сканера.

- Утверждены одно независимое ядро Release Core и небольшие адаптеры Codex, Harness, Claude Code, Hermes.
- Основным планируемым средством распространения выбран официальный GitHub CLI; Python-установщик сохранён как минимальный офлайн-резерв.
- Закреплён минимальный стек распространения через GitHub CLI и Python; NVIDIA SkillEvaluator ограничен бесплатным Tier 1 после отдельной проверки, Tier 2/3 и обязательные платные AI API запрещены.
- Запланированы эталонный валидатор Agent Skills `skills-ref` и отдельная оценка затрат/качества NVIDIA Tier 1.
- Обновлены архитектура, правила работы с репозиторием и полные английские переводы без изменения работающих скриптов.

**Статус:** изменения документации и политики. Запланированные инструменты не установлены, а межагентные интеграции не проверены.

## 0.0.1 — Введена обязательная микроверсионность каталога

- Для TESSERA закреплены те же правила, что и для Microversion Release: шаг PATCH+1, релизные рубежи `.99`, продолжение `.100+` при незавершённой задаче.
- Добавлен единый источник версии `VERSION` и проверка переходов при каждом изменении.
- Настроено создание аннотированного Git-тега после успешной проверки изменений в `main`.
- Уточнены русские и английские инструкции по разработке и выпуску версий.
- Ранее добавленные английские переводы и языковая политика сохраняются; опубликованная история не переписывается.

**Ограничение:** создание тега зависит от прав GitHub Actions. Настоящие сборочные артефакты и GitHub Release не создаются автоматически.
